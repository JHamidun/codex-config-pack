# Native video production and editing

Resolve the requested result and preserve the selected guide's actual method:
footage edit, vertical montage, product-motion/Remotion, shot planning or generated
footage are distinct workflows. Read only the relevant shot/montage/reference cards.
Do not replace real footage with generated visuals or an editable timeline with a
flattened image sequence without the user's choice.

Use an installed native video/Remotion capability and its documented runtime first.
For local deterministic editing, inspect available FFmpeg/FFprobe or the project's
locked media dependencies, probe actual input streams, and write explicit project-
owned commands with bounded execution. No source wrapper, hardcoded avatar/voice,
private token file, fixed upload destination or author-specific home is an input.

Keep a project manifest of source paths/hashes, shot IDs, durations, frame rate,
resolution, overlays, captions, audio and output. Validate source rights and identity/
voice permission. Use the requested portrait, logo and typography, not fabricated
substitutes. Preserve non-destructive originals and reject accidental overwrites.

For generated footage, TTS/music, transcription or an explicitly chosen service,
discover its actual authorized native connector. Confirm cost and input sharing when
required. Submit only the scoped job, track its real ID through completion, and verify
the returned media. No stale model IDs or silent paid-provider fallback.

Render the actual timeline, probe duration/streams/dimensions/frame rate, inspect
representative frames and transitions, and listen to the soundtrack where supported.
Check subtitles, sync, cropping, black/silent gaps and end card. Separate automated
stream checks from visual/audio review. Do not claim review of unobserved footage.
Return the actual video and project when requested; publishing/upload is separate
and requires exact destination/visibility authorization plus readback.

The public shot references are retained, but quarantined demo/template code is not
an installed Remotion project. Use current native tooling to implement the selected
shot; unavailable licensed fonts/audio/binaries must be supplied or replaced by
authorized equivalents. State missing specialized runtime/connector capabilities.
